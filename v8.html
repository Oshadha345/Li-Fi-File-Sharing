The Flaw of Standard Systems

Traditional hydration systems fail because they ignore actual human behavior. We solved this.

Standard Timers

  • Uses static, fixed intervals (e.g., exactly every 40 mins).
  • Causes "Alarm Fatigue" — users ignore the buzzer over time.
  • Ignorant of volume: Alarms even if you just drank 5 minutes ago.

Bottle Mate Innovation

  • Dynamic Rate Tracking: Focuses on ml/minute intake velocity, not just volume.
  • Rewards Good Habits: Automatically delays alerts if you drink proactively.
  • State Awareness: Knows when the bottle is lifted vs resting using deadband filtering.

The Adaptive Control Algorithm

To score high marks in embedded systems, the logic must be robust. Instead of a countdown, we implemented a continuous feedback loop. Click below to expand the engineering mathematics.

We establish a baseline requirement for healthy hydration. For our system, the target is 100ml every 40 minutes.

R = Sideal / Tideal
R = 100ml / 40min = 2.5 ml/min

When a sip is detected (a drop in weight > 10g deadband), the system evaluates the user's actual performance.

Ruser = Saccum / Telapsed

Where Saccum is total water consumed, and Telapsed is time since the cycle began.

The remaining time to the next alert is dynamically adjusted using the differential between the ideal rate and the user's rate.

Tremain,new = Tremain,old + k × (Ruser - R) × Tideal
  • If R_user > R : User is ahead of schedule. Time is added (Alert Delayed).
  • If R_user < R : User is behind schedule. Time is reduced (Alert Sooner).

Calculation Event (LIFTED → NORMAL)

When transitioning back to NORMAL, the system calculates Delta Weight. If Delta > 0, it registers as a sip, calculates the Adaptive Timer Bonus via `sip_ml * 24s`, and clamps it between physical limits.

ISR & Parallelism

Concurrent hardware interrupts bypassing the need for an RTOS.

TIMER0_COMPA_vect

1ms Precision Tick

Handles the core `millis()` 32-bit counter. Furthermore, it implements a non-blocking countdown for tone durations. When a tone is requested, `v_tone_dur` is set. This ISR decrements it every 1ms and physically disables Timer2 (Buzzer PWM) when it hits zero, ensuring the main loop never blocks during audio playback.

Prescaler: 64 | OCR0A: 249 | Freq: 1000 Hz

TIMER1_COMPA_vect

1s State Dispatcher

Timer1 operates entirely independently to trigger macro-level system updates. Once per second, it sets a volatile variable `v_flagTick = 1`. The main loop continuously checks this flag. If set, it clears it and dispatches the State Machine, updating UI timers and checking for EEPROM auto-saves.

Prescaler: 256 | OCR1A: 62499 | Freq: 1 Hz

TIMER2_COMPA_vect

Dynamic PWM Generator

Dedicated strictly to audio. The `OCR2A` register is mathematically re-calculated on the fly using a 32-bit division routine based on the requested frequency. This ISR fires at twice the target audio frequency to toggle the `PB2` pin, generating a perfect square wave without utilizing CPU cycle delays.

Prescaler: 64 | OCR2A: Dynamic | Freq: Variable Audio

Assembly Source Core

Low-level execution details bypassing HAL abstractions.

; Timer0 Compare A ISR — fires every 1ms @ 16MHz
; CTC mode, prescaler 64, OCR0A = 249

TIMER0_COMPA_vect:
    push   r16
    in     r16, SREG          ; Save status register
    push   r16

    ; ─── Increment 4-byte millis counter ───────────────
    lds    r16, v_millis
    subi   r16, 0xFF         ; Adds 1 (carry-propagating trick)
    sts    v_millis, r16
    lds    r16, v_millis+1
    sbci   r16, 0xFF         ; Propagate carry to byte 1
    sts    v_millis+1, r16
    ; ... bytes 2, 3 ...

    ; ─── Tone duration countdown ────────────────────────
    lds    r16, v_tone_active
    tst    r16
    breq   t0_done           ; Skip if no tone active
    lds    r16, v_tone_dur
    lds    r17, v_tone_dur+1
    subi   r16, 1
    sbci   r17, 0
    or     r16, r17
    brne   t0_done
    
    ; Tone expired: stop Timer2, clear buzzer
    sts    TCCR2A, r16
    sts    TCCR2B, r16
    cbi    PORTB, BUZZER_BIT
t0_done:
    pop    r16
    out    SREG, r16
    pop    r16
    reti

; hx711_read_raw — Bit-bang 24-bit read from HX711
; Returns: r16:r17:r18 = 24-bit value (sign-extended → r19)

hx_ready:
    cli                          ; Disable interrupts during critical timing
    ldi    r18, 0               ; MSB (byte 2)
    ldi    r17, 0               ; byte 1
    ldi    r16, 0               ; LSB (byte 0)
    ldi    r20, 24              ; 24 data bits

hx_bit_loop:
    sbi    PORTD, HX_SCK_BIT   ; SCK HIGH (rising edge)
    nop                          ; Timing margin (≥0.2µs)
    nop
    clc                          ; Clear carry
    sbic   PIND, HX_DOUT_BIT    ; Sample DOUT (MSB first)
    sec                          ; Set carry if DOUT=1
    rol    r16                   ; Shift carry into r16
    rol    r17
    rol    r18
    cbi    PORTD, HX_SCK_BIT   ; SCK LOW
    dec    r20
    brne   hx_bit_loop

    ; 25th pulse → set gain=128 for next conversion
    sbi    PORTD, HX_SCK_BIT
    nop
    nop
    cbi    PORTD, HX_SCK_BIT
    sei                          ; Re-enable interrupts

    ; Sign extend 24→32 bit
    ldi    r19, 0
    sbrc   r18, 7               ; If bit 23 set (negative)
    ldi    r19, 0xFF            ; Sign extend high byte

; tone_start — Non-blocking tone using Timer2 CTC + ISR toggle
; r24:r25 = frequency Hz, r22:r23 = duration ms

tone_start:
    sts    v_tone_dur, r22
    sts    v_tone_dur+1, r23

    ; OCR2A = (125000 / freq) − 1
    ldi    r16, 0x48           ; 125000 = 0x01E848
    ldi    r17, 0xE8
    ldi    r18, 0x01
    call   div32_signed        ; r16 = OCR2A+1
    dec    r16                 ; OCR2A value

    ldi    r16, (1<<WGM21)    ; CTC mode
    sts    TCCR2A, r16
    sts    OCR2A, r16         ; Set compare value
    ldi    r16, (1<<CS22)    ; Prescaler /64
    sts    TCCR2B, r16

    lds    r16, TIMSK2
    ori    r16, (1<<OCIE2A)  ; Enable Timer2 CompA interrupt
    sts    TIMSK2, r16
    ldi    r16, 1
    sts    v_tone_active, r16
    ret

TIMER2_COMPA_vect:
    sbi    PINB, BUZZER_BIT    ; Atomic toggle of PB2
    reti

; div32_signed — 32-bit signed integer division
; Dividend: r16:r19  Divisor: r20:r23

div32_signed:
    ; Determine result sign via XOR of sign bits
    mov    r2, r19
    eor    r2, r23             ; XOR → bit7 = result sign

    ; Restoring division — 32 iterations
    ldi    r24, 32
d32_loop:
    lsl    r16               ; Shift dividend left
    rol    r17
    rol    r18
    rol    r19
    rol    r8                ; Into remainder r8:r11
    rol    r9
    rol    r10
    rol    r11
    
    cp     r8, r20           ; remainder ≥ divisor?
    cpc    r9, r21
    cpc    r10, r22
    cpc    r11, r23
    brlo   d32_skip
    
    sub    r8, r20            ; Subtract divisor
    sbc    r9, r21
    inc    r4                 ; Set quotient bit
d32_skip:
    dec    r24
    brne   d32_loop
