Optical Wireless Communication System (IR Data Link)

Engineering a Bare-Metal, Secure Optical Data Link via OOK Modulation and Hardware Encryption.

Core Mission: To design and implement a robust, unidirectional optical data transmission system using custom-etched PCBs, completely immune to ambient light interference.

Traditional wireless communication relies on crowded RF bands. Our project explores Free-Space Optical communication using infrared light. We initially prototyped a baseband system using a high-power 1W visible LED, but sunlight and room lighting saturated the receiver and broke long-distance reliability. We then engineered a strict modulated IR architecture using a 940nm IR LED, a stable 38kHz carrier, and hardware On-Off Keying through external CMOS logic to produce a dependable, noise-immune wireless serial cable.

Evolution: Baseband to Modulated IR

The first prototype used a 1W visible LED in baseband mode. It worked in controlled conditions but failed under sunlight and ambient illumination. The final architecture shifted to 940nm IR with a 38kHz carrier and TSOP1838 demodulation, dramatically improving immunity to environmental light and producing stable free-space communication.

Deep Dive: OOK Modulation and Carrier Math

Hardware gating and timer synthesis guarantee stable carrier generation with almost zero firmware overhead.

Double Inversion Trick

Standard UART idles at HIGH (5V). We route TX through a 74HC04 inverter so idle becomes LOW (0V), preventing continuous IR emission. This saves LED current, prevents unnecessary heating, and avoids AGC desensitization in the TSOP1838 during idle windows.

Carrier Generation (Timer2 CTC)

f_carrier = f_clock / (2 * N * (1 + OCR2A))

With f_clock = 16MHz and N = 1, selecting OCR2A = 209 yields exactly 38.095kHz. The toggling happens in hardware compare mode, so the CPU is free for keypad scanning and serial framing.

AND Gate OOK Mixer

74HC08 performs m(t) * c(t): data and carrier are multiplied in logic hardware. Logic 1 data passes the 38kHz carrier; logic 0 data suppresses emission. The result is clean OOK bursts compatible with TSOP demodulators.

S(t) = m(t) * c(t)

Security: Symmetric XOR Cipher

Inline byte masking at assembly level, aligned with tight AVR constraints.

AES-class ciphers are expensive for an 8-bit AVR under strict RAM and timing limits. XOR encryption maps directly to a single-cycle eor instruction, giving deterministic low-latency transformation in the UART path.

Plaintext XOR Secret Key (0x5A) = Ciphertext

On the receiver, applying the same key (0x5A) with eor reverses the transformation exactly, restoring plaintext before OLED rendering.

Bandwidth Limits

At 115200 baud, symbols become too short for robust 38kHz envelope extraction. 9600 and 2400 offer reliable demodulation margins in real rooms.

Photodiode Saturation

Strong direct flashlight exposure can saturate the sensor front-end and temporarily reduce dynamic response.

Line-of-Sight

Optical beam obstruction can introduce corruption or packet loss, requiring careful placement in deployments.

;==========================================================================
; CARRIER_INIT: Generates continuous 38kHz square wave on PB3 (Leg 17)
; Uses Timer2 in CTC Mode. Calculation: 16MHz / (2 * 1 * 38000) - 1 = 210
;==========================================================================
CARRIER_INIT:
    in    r16, DDRB
    ori   r16, (1<<3)               ; Set PB3 as Output
    out   DDRB, r16
    ldi   r16, 210
    sts   OCR2A, r16
    ldi   r16, (1<<COM2A0) | (1<<WGM21)
    sts   TCCR2A, r16
    ldi   r16, (1<<CS20)
    sts   TCCR2B, r16
    ret
; --- NEW: Encryption Subroutine ---
USART_TRANSMIT_SECURE:
    push  r17
    ldi   r17, SECRET_KEY           ; Load the secret key
    eor   r16, r17                  ; Encrypt the character in r16
    rcall USART_TRANSMIT            ; Send the garbled byte over IR
    eor   r16, r17                  ; Restore r16 to its original value just in case
    pop   r17
    ret
MAIN_LOOP:
    lds   r16, UCSR0A
    sbrs  r16, RXC0                 ; Wait for data from the VS1838B
    rjmp  MAIN_LOOP

    lds   r16, UDR0                 ; Grab the received encrypted byte

    ; --- NEW: DECRYPTION STAGE ---
    push  r17
    ldi   r17, SECRET_KEY           ; Load the secret key
    eor   r16, r17                  ; Un-garble it back into readable ASCII!
    pop   r17
    ; -----------------------------
TWI_WRITE:
    sts   TWDR, r16                 ; Write byte into TWI data register
    ldi   r16, (1 << TWINT) | (1 << TWEN)
    sts   TWCR, r16                 ; Trigger transmission
TWI_WRITE_WAIT:
    lds   r16, TWCR
    sbrs  r16, TWINT                ; Wait for completion
    rjmp  TWI_WRITE_WAIT
    ret

Important Engineering Decisions

Bandwidth: Why not 115200 baud?

At 115200 baud, each bit is about 8.6us and may not provide enough 38kHz cycles for stable TSOP envelope recovery. Lower baud operation improves BER in realistic ambient conditions.

Photodiode saturation concern

Strong direct illumination can saturate the sensor front-end. Normal indoor ambient is filtered, but intense directed light can temporarily blind valid bursts.

Full-duplex scaling challenges

Bidirectional optical links require crosstalk controls such as WDM bands (for example 850nm and 940nm) or strict TDM scheduling and synchronization.
